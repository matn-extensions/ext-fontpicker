# Interactive Font Picker

Interactive modal to scan, preview, and select system TrueType/OpenType fonts

## Details
- **Identifier**: `matn.ext.fontpicker`
- **Version**: `1.0.0`
- **Category**: `tools`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Interactive Font Picker**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-fontpicker
```
